# Legacy Native PySide6 UI Subsystem

> **Note:** This directory contains the original Phase 1 native PySide6 (QWidget) user interface pages and main window.
>
> The active production application has been modernized to use **`MainWindowWeb`** (`src/ui/main_window_web.py`) hosting the local HTML5/Tailwind CSS/JavaScript web engine (`src/ui_web/`) via QtWebChannel.
>
> These files are retained here for reference, regression testing, and fallback capability.
