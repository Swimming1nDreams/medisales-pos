# Project Archive & Historical Backups

This directory contains historical checkpoints and legacy backups preserved for audit and historical reference:

- **`phase_backups/`**: Snapshots from earlier implementation phases:
  - `backup_phase13/`: State before Phase 13 localization and reports enhancements.
  - `backup_phase16_ui_web/`: Prototype backup from early WebEngine experiments.
  - `backup_refinement_pass/`: Intermediate refinement snapshot.

The active, maintained source code resides exclusively under `src/`.
